## Narration

> AI can help improve your CV, but it should never invent your experience. Start with what you really did: a task, a responsibility, or a result you can honestly explain. Then ask AI: “Make this clearer and more professional without adding any facts.” Read every line carefully. Is it true? Does it still sound like you? If not, edit it. Keep your experience yours; use AI to explain it clearly. Save this for your next CV update.
